## "命令面板新交互没生效"排查（根因：exe 是旧 dist）

- 现象：用户反馈命令面板还是旧交互。排查：代码与 dist 都是最新的
  （dist 9/7 18:32），但用户运行的 `target/debug/ops-workbench.exe` 是
  **9/7 18:10** 构建的（早于命令面板改版与 splash 布局改动完成）——上次
  cargo build 被取消，exe 一直没重嵌新 dist。
- 修复：touch `build.rs` + `cargo build`（40.9s 成功；用户已关闭旧实例，
  否则 os error 5 锁 exe）。9/8 9:18 新 exe 链接完成，用户重启后生效。
- **教训（勿忘）**：前端改完只跑 `pnpm build` 对用户不可见——必须
  `touch src-tauri/build.rs` + `cargo build`（或 pnpm tauri dev）才有新 UI；
  用户报"没生效"先 diff dist 时间 vs exe 时间，再查进程在跑哪个 exe。
  （注：`cargo build` 的 debug exe 嵌入的是构建时的 frontendDist，
  `devUrl` 只在 `tauri dev` 时生效——直接双击 debug exe 看到的是嵌入 dist。）
