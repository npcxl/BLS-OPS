### 完成
- **统一 Provider API**：`OpenAiCompatibleAdvisor::new(config, api_key)` 两参（明文 http 策略
  只有一个来源 `config.allow_insecure_http`，保存校验 / 连接测试 / 正式复核同一段代码）；
  `review(&prompt, &cancel)` 返回 `AiReviewOutcome{result, attempts}`；`AiCancel` 是
  `tokio::sync::watch`（不是 AtomicBool），配合 `tokio::select!` 打断请求与退避等待。
- **真实取消**：复核命令拆出 `run_review` → `ReviewRun{Succeeded/Failed/Cancelled}`；
  调用前 / 解析后 / **写库前**三重检查取消；取消绝不写 proposal、不记 knowledge_usage、
  不改 AI 指纹；成功/失败/取消三种终态都 `AiReviewRegistry::forget`。
- **真实 attempts**：任务表与 `proposal.ai_review.attempts` 写 Provider 统计值；错误码按
  `AiRejectionKind` 映射（markdown/command/fake_citation/modification_attempt…），不再一律
  `provider_error`。
- **服务器能力快照**：`DeploymentProposal.server_capability: Option<ServerCapabilitySnapshot>`
  （`#[serde(default, skip_serializing_if)]` 兼容老库；`output_hash` 里清零 → 不参与可复现哈希）；
  引擎生成时写入，AI 复核只读快照，缺失明确 `{"status":"unknown"}`。
- **默认 Provider 一致性**：`db::set_default_provider` 先校验存在 + 已启用，再用
  `unchecked_transaction` 切换；无效 id 不清空现有默认；`ai_provider_save` 对 disabled 强制
  `is_default = false`。
- **知识库后端**：`deployment_knowledge_update_meta`（只改元数据、不产生新版本）、
  `deployment_knowledge_import_markdown`（受限：`.md/.markdown/.txt` + 2 MiB + UTF-8，只返回
  内容不落库）。
- **前端**：新建 `src/workbench/settings-ai.tsx`（设置页「AI 模型」：列表/新建/编辑/删除/测试/
  设默认；编辑不回显 Key、留空即保留；删除询问是否同步删 Keyring 密钥）；`ai-review.tsx`
  状态机（每个状态**只有一个**主按钮：idle→运行、running/queued→取消、failed→重试、
  succeeded→再跑一次）；成功后 `deploymentProposalGet` 拉回并写回上层；「没有方案」与
  「没有 Provider」分开（前者 "No proposal generated yet"，后者给可点击的"前往设置"）；
  `knowledge-panel.tsx` 加 enabled 开关 / 状态 / 核对时间 / 备注 / 归档确认 / 导入 Markdown /

## P5.6 阶段二：P3 Git 来源 + P4 ProjectAnalysis（已完成）
- **Git 来源**：`artifact/git.rs` + `ImportSource::GitRepository{url,revision,subdirectory,credential_ref,shallow,include_submodules}`。
  URL 校验禁 `https://user:pass@` 与 `https://<token>@`（SSH `git@host:path` 允许）；clone 参数是
  `Vec<OsString>` **结构化构造**（测试直接断言"无 shell 痕迹 / 默认 --depth 1 / core.hooksPath /
  submodule.recurse=false / credential.helper= / 无 --recurse-submodules"）；凭据只经**子进程环境变量**
  `GIT_CONFIG_*` + `http.extraHeader` 注入（不进参数、不写 .git/config、不进日志）；另有
  `GIT_TERMINAL_PROMPT=0` / `GIT_LFS_SKIP_SMUDGE=1`；缓存目录用 URL+revision 的哈希命名（URL 不落盘）。
- **统一 SourceSnapshot**（`artifact/snapshot.rs`）：Git/本地目录/压缩包 → 同一种不可变快照
  （`origin` + `commit_sha` + `content_fingerprint` + `scanned_at`），指纹复用既有 `hash_source`。
- **ProjectAnalysis**（`deployment/analysis.rs`）：复用 `ArtifactInspection` 投影出类型/多服务/栈/端口/
  健康检查/env 名/secret-like 名/外部依赖/阻塞(Blocked)/未知(Unknown)/证据；`ai_payload()` 是**唯一**
  允许进提示词的项目侧内容；`sanitize_fragment()` 只放行 18 个清单文件（拒绝 `.env`/私钥/源码），
  8 KiB 上限**超限直接拒绝不截断**，且值里含 `://user:pass@` 的连接串也会被抹值留键名。
