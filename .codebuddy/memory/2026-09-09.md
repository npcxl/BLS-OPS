### 回归：裁剪改动让 hover 整个消失（同日）

- 现象：用户能看到线条（说明 hover 生效）→ 我改完裁剪后"没 hover 效果了"。
- 根因：`BlockGeometry` 新增**必填** `viewportHeightPx`，热更新下组件/纯函数模块版本错配时旧调用方不传 → `rowsTopPx + undefined = NaN` → `bottom <= top` 对 NaN 恒 false → 高亮矩形是 NaN，视觉上完全消失。
- **修复（模式化）**：接口新增几何字段一律设为**可选 + 防御**（`viewportHeightPx?`；`viewBottomPx()` 在缺失/≤0 时返回 `+Infinity` = 退化为不裁剪）。原则：**新增裁剪类几何参数必须可缺失，缺了宁可多画也不能让高亮消失**。并加回归测试（缺字段时必须仍返回完整矩形）。
- 验证：纯函数 22✓ / 全量 738✓ / pnpm build ✓。
