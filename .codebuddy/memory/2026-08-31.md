## P0 返工：把 BLS-OPS 从 UI 外壳改成真正的 SSH 工具

验收不通过后的整体返工，范围：移除全部假数据 + 打通真实 SSH 链路。

### 后端（src-tauri）
- `db.rs`：新增 `user_version` 迁移机制（`migrate()`，当前 SCHEMA_VERSION=2），v1→v2 加 `servers.favorite` / `servers.last_connected_at` / `credentials.passphrase_ref`，新增 `server_groups` 表；删除未使用的 `quick_commands` 与 `delete_server`/`list_sessions`。
- `db.rs` 新增：`delete_server_cascade`（级联清会话/历史/跳板机引用）、`delete_credential`（解除服务器引用）、`set_server_favorite`、`touch_server_connection`、`trust_known_host`（upsert）、`delete_known_host`、`list_recent_sessions`、`update_session_status`。
- `ssh.rs` 全量重写：`ConnectTarget/ConnectOutcome/CredentialSecrets`、`parse_ssh_target`（支持 IPv6 与端口校验，7 个单测）、密码 / 私钥 / 私钥+口令 认证、KeepAlive（russh `keepalive_interval` + `ssh_keepalive` 命令）、ProxyJump（`channel_open_direct_tcpip` + `connect_stream`，跳板 handle 存入 `chain` 保活）。
- **Host Key**：`check_server_key` 拒绝未信任/已变更指纹，握手失败被转成 `HostKeyUnknown`/`HostKeyChanged` 数据返回（不是静默成功，也不是普通错误）。
- `commands.rs`：删除 `credential_get_secret`；新增 `server_set_favorite`、`server_test_connection`、`group_*`、`known_host_delete`、`known_host_trust`、`session_list`、`session_stats`、`ssh_keepalive`、`ssh_status`、`app_info`。`credential_save` 先写 Keyring，DB 失败时回滚 Keyring 条目（避免孤立凭据）；新凭据强制要求密钥材料。
- 测试：`cargo test` 21 个通过（ssh 7 + db 9 + commands 5）。
