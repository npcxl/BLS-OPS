# 2026-09-04

## 文件夹图标改 Windows 黄（用户反馈"文件夹太暗"）
- vscode-icons 的 `default-folder` 是暗蓝灰色，在应用底色上几乎不可见。用户要求"像 Windows 一样"。
- 考察：fluent-color `document-folder` 是紫色系不用；fluent-emoji `file-folder`（3D 风）与 **fluent-emoji-flat `file-folder`**（扁平）都是 Windows 黄——flat 版配色 `#ffb02e`+`#fcd53f`，32 viewBox，小尺寸（14px 行内）更清晰 → 选 flat。
- 改动：`scripts/generate-file-icons.mjs` 的 COLLECTIONS 加 `fluent: @iconify-json/fluent-emoji-flat`，`folder` 候选链改 `["fluent:file-folder", "default-folder"]`；重跑 `pnpm icons:regen`；`@iconify-json/fluent-emoji-flat` 进 devDeps（仅生成期）。
- **取舍**：只换默认 `folder`；特殊文件夹（folder-git/node/docker 等）保留 vscode-icons 徽章图标保辨识度——用户若嫌暗可再统一。
- Iconify 对象数据带 width/height=32，但 EntryIcon 显式传 width={14} 覆盖，无影响。验证：pnpm build 6.66s ✓。
- 踩坑复发：PowerShell 内联 `node -e` 正则转义再次解析失败且**导致同命令行里 pnpm add 也没执行**（`cmd1; node -e ...` 解析失败=全行不跑），复杂校验一律临时 .mjs。
