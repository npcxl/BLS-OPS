## 3. 状态机

```text
created → importing → analyzing ─┬→ needs_input ─┐
                                 └→ draft_ready → confirming → preflight → deploying
                                                     ↑            ↓            ↓
                                              （输入变化/阻塞）  succeeded / failed / rolled_back
任意阶段 → cancelled
```

迁移规则唯一来源：`SessionStatus::can_transition_to()`。
`preflight` 有阻塞 → 回 `needs_input`，**绝不启动**。

## 4. 安全边界

1. **确定性规则引擎仍是拓扑 / 容量 / 工作流 / 风险结论的唯一来源**；AI 只产出结构化意图。
2. **AI 无法产出命令**：草案 `deny_unknown_fields`，`command/cmd/shell/script/entrypoint/args`
   出现即整份解析失败；编译器 `args` 恒为空、可执行名来自白名单、镜像须已登记。
3. **用户确认前不改服务器**：`confirm_and_start` 是唯一入口，且门禁六道全过才启动。
4. **Secret 明文只在 Keyring 与执行瞬间**；不进 AI、不进 Memory、不进 SQLite、不进日志。
   Git 凭据只经**子进程环境变量**注入，不进参数、不写 `.git/config`。
5. **发往 AI 的内容受限**：`ProjectAnalysis::ai_payload()` + 白名单清单片段（8 KiB 超限直接拒绝）。
6. **Memory 不能改安全策略/审批/路径围栏** —— 受控 key 里根本没有这些字段。
7. Memory 单次选择只是 `pending`，不会自动变成全局默认。

## 5. Memory 自动写入规则（确定性，AI 不参与）

| 场景 | 结果 |
| --- | --- |
| 单次临时选择 | `pending`，置信度 30，**不参与**草案 |
| 连续多次同一选择 | 50 + 10×(n−1)，≥70 自动 `active` |
| 用户明确表达 | 直接 `active`，置信度 90 |
| 部署成功 | `success_count + 1`，置信度 +5 |
| 部署失败 / 回滚 | `failure_count + 1`，置信度 −15，<30 退回 `pending` |
| 用户修改草案 | 生成 **correction 候选**（`pending`，需用户确认） |

## 6. 幂等与取消

* `confirm_and_start` 接受 `idempotency_key`：同键第二次直接回放上次结果，**不产生第二个 Plan/Run**；
* 门禁顺序固定：幂等 → 状态 → 指纹 → 计划 → 预检 → 审批（测试钉死）；
* 输入指纹变化（项目 / 服务器 / 描述 / Memory 引用）→ 旧草案作废，必须重新分析。

## 7. AI 输入 / 输出

* **输入**：`ProjectAnalysis::ai_payload()`、用户描述、服务器能力摘要、容量、被检索到的
  `MemoryHit[]` / `KnowledgeHit[]`；
* **输出**：`AiDeploymentDraft`（`deny_unknown_fields`），字段见
  `deployment/planner/model.rs`；
* **校验**：引用真伪、服务器支持的拓扑/运行时、shell 元字符、路径围栏、依赖与域名指向 —— 全部
  返回结构化 `DraftRejection` / `CompileIssue`，不静默丢弃、不偷偷降级。

## 8. DNS 为什么仍需要人工操作

仓库**没有任何**能写 DNS 的适配器（`DnsProvider::supports_automation()` 全为 `false`）。
因此：没有可用 Provider → 生成人工步骤（告诉用户该加哪些 `A`/`TXT` 记录）→ 暂停 →
用户验证解析 → **只有明确解析到目标 IP** 才允许 HTTP-01；通配域名与 DNS-01 继续人工。
Cloudflare / 阿里云 / 腾讯云已在 `KNOWN_PROVIDERS` 预留（凭据将来只进 Keyring）。
