## 结果面板内搜索（增强终端） + 移除终端 scrollback 搜索

- 用户需求：① 结果里能搜索并高亮；② 去掉命令面板（终端工具栏）顶部的搜索图标与相关功能。
- 实现：
  - 新纯逻辑 `views/terminal/result-search.ts`：`normalizeQuery`/`findRanges`/`segmentLine`/`countHits`。
    **逐字符推进而非 `indexOf` 步进** —— needle 自身重叠时（`aa` 在 `aaaa`）后者会漏配。
    `segmentLine` 保证"拼接片段 === 原文"（单测断言），搜索绝不篡改内容。
  - 新 UI `views/terminal/ResultSearchBar.tsx`（搜索框 + `n 处匹配` + Esc 关闭）。
  - 搜索状态在 `TerminalResultDrawer`：抽屉条右侧放大镜开关；**切换结果 Tab 时渲染期清空搜索词**（搜索词属于当前那条结果）；命中数用 `useMemo` 按 `renderedText` 统计，与高亮范围一致。
  - 高亮渲染：`TerminalSnapshotView` 内 `HighlightedLine` + `RawStreamView` 内 `Highlight`，命中包 `<mark data-testid="result-search-hit">`。
  - **`JsonView` 本来就有自己的树内搜索**（关键词过滤 + 命中列表 + 复制完整值）→ 结果搜索栏不注入 JSON 视图，避免双搜索打架。
- **移除 scrollback 搜索**：删 `use-terminal-search.ts`（已无引用）、`terminal-toolbar.tsx` 的搜索图标与输入框区块、`use-terminal-menu.ts` 的"Search"菜单项、`TerminalView` 的接线与 props。
- CSS：`globals.css` 加全局 `mark` 样式（浏览器默认黄底黑字在暗色主题刺眼）→ `rgb(var(--accent)/0.28)` 底 + `color: inherit`。
- i18n：`Search in result` / `{{count}} matches` / `Close search` 补 zh-CN + zh-TW。
- 测试：`test/result-search.test.ts` 14 个（含 needle 重叠、中文、片段拼接守恒）。

## 全局禁用 WebView 原生右键菜单

- 用户报"我们是软件，为什么右键能刷新" —— 根因：**从未禁用 WebView2 内置右键菜单**，只有自绘菜单区域（终端/文件树）自身 `preventDefault`，空白处就漏出浏览器原生菜单（刷新/检查/另存为）。
- 修复 `src/main.tsx`：全局 `contextmenu` 监听，**`import.meta.env.DEV` 时放行**（保留 WebView 检查器可调试），生产构建 `preventDefault()`。
  - 自绘菜单不受影响：它们在各自容器上自己 preventDefault，全局这层只杀"没人认领"的原生菜单。
  - 用户裁决：全局禁掉（推荐项）。F12 仍可用于 DevTools。
- 验证：pnpm build ✓ / 752 测试全绿 ✓ / cargo build ✓ exe 已重嵌。

## 终端 Ctrl+C/V + 右键粘贴（用户需求）

- `lib/clipboard.ts` 新增 `readText(): Promise<string | null>`（`null`=读取失败/无文本；**空串是有效结果**，不能与失败混淆）。
- `TerminalView.pasteIntoTerminal`：`readText` → `\r?\n → \r`（Shell 只认 `\r`，直接送 `\n` 会粘出一堆未提交的 `^J`）→ **同一个 `writeToShell` 出口**（占位符最后一道拦截照常生效）→ 行编辑器同步 feed（否则下次补全拿旧行算差集）。读失败 `setParamHint` 可见提示，绝不静默。
- **Ctrl+C 双重身份分流（关键）**：`event.code === "KeyC"`（物理键，非英文布局下 `key` 会变）——
  - **有选区** → 复制 + `clearSelection()` + 拦下；
  - **无选区** → `return false` 穿透给 shell 发 **SIGINT**（终端最不能丢的语义，中断跑着的命令）。
- Ctrl+V 恒粘贴（拦下避免 xterm 把 `\x16`(^V) 当可打印字符送进 shell）；**Shift+Insert** 传统终端粘贴键一并支持。
- 右键菜单（`use-terminal-menu.ts`）首位加 复制(有选区才出现，hint Ctrl+C) / 粘贴(hint Ctrl+V, 未连接 disabled)，后接 separator。复制项**只在有选区时出现**——无选区给"复制"会误导（那是 SIGINT）。
- i18n：`Copy` / `Paste` / `Paste failed — the clipboard could not be read` 补 zh-CN + zh-TW（这两个 key 之前不存在）。
- 验证：pnpm build ✓ / 752 测试全绿 ✓ / cargo build ✓ exe 已重嵌。

## 剪贴板改走 Rust 插件（修 WebView2 权限弹窗）

- 用户报"为什么 http://tauri.localhost 想要查看复制到剪贴板的文本和图像" —— 根因：`navigator.clipboard.readText()` 触发 **WebView2 原生剪贴板权限门禁**（`http://tauri.localhost` 是 WebView 页面源）。
- 修复：装 `tauri-plugin-clipboard-manager`（Rust 读写剪贴板，**无权限弹窗**）：
  - `lib.rs` 注册插件；capabilities 只放行 `allow-read-text`/`allow-write-text`；
  - `lib/clipboard.ts` 的 `copyText`/`readText` 内部改调插件 —— **统一出口不变，所有调用方零改动**。
- **顺手清掉散落的裸 `navigator.clipboard`**（4 处：`ServiceManagerView` ×2、`RemoteFilePanel` ×2、`ErrorBoundary` ×1）→ 全部收敛到 `copyText`，否则那些位置仍会弹窗。
- **测试基建（重要）**：换实现后 30 个测试挂（8 个文件 mock `navigator.clipboard` 失效）→ 新增 `src/test/setup-clipboard.ts` 并接入 `vite.config.ts` 的 `test.setupFiles`：
  - mock `@tauri-apps/plugin-clipboard-manager` → **转发到 `navigator.clipboard`**（不是自己存内存！）。
  - **关键原因**：既有用例靠 `vi.spyOn(navigator.clipboard,"writeText").mockRejectedValue()` 断言"复制失败要提示"，转发才能让这些 spy 继续生效；自己存内存会让它们全部静默通过/失败。
  - 同时补 happy-dom 缺失的 `navigator.clipboard` 最小实现。
- 教训：**改底层实现（换了通道）时，先看测试 mock 的是哪一层**；setup 替身要转发到原可观测面，否则几十个用例一起挂。
- 验证：pnpm build ✓ / 752 全绿（含先前挂的 30 个）✓ / cargo check ✓ / cargo build ✓ exe 已重嵌。
