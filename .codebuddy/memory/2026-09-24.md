## SFTP 报错统一为人话（含路径）

用户报"经常 SFTP 错误 No such file"，选择"都给统一人话提示 + 覆盖所有位置"。

- 根因：`ssh/sftp.rs::sftp_error()` 只翻译了 PermissionDenied，其余一律 `SFTP 错误：{status.error_message}` —— 服务器把协议错误码名（`No such file`）当说明返回，原样透给用户等于没说。
- 改动：签名改为 `sftp_error(path: &str, error)`，按状态码分支翻译（NoSuchFile→路径不存在或已被删除 / PermissionDenied→权限不足 / OpUnsupported / NoConnection|ConnectionLost / Failure），并带上出错路径；`path == ""` 时省略路径段（`sftp_close` 用）。
- 调用点全量更新（33 处）：`ssh/sftp.rs`、`editor_sync.rs`、`editor_sync/sync.rs`。`ssh/session.rs` 删掉从未使用的 `use super::sftp::sftp_error;`。
- 顺手发现：`sftp_list_dir` 原来 `canonicalize(requested)` 会 move 掉 `requested`，改成 `canonicalize(requested.as_str())` 才能把路径留给错误信息。
- 测试：`ssh/tests.rs` 新增 4 个（缺路径 / 权限 / 空路径省略段 / 未映射码保留原文）。验证：cargo fmt --check ✓、cargo check --all-targets ✓、cargo test --lib 359 全过 ✓、cargo build ✓。

## 真 bug：文件面板跟随 cd 时基准目录用错（cd 后 100% 报 SFTP 路径不存在）

用户描述"终端在 A、右侧面板在 B，在终端 cd 之后右侧百分百报错"。

- 根因：`RemoteFilePanel` 跟随 `cd` 时用的是**面板自己的 cwd**（`nav.stack[nav.index]`）当基准：
  `target = joinPath(panelCwd, arg)`。面板可以被用户手动导航到任意目录，与终端 cwd 不同步 → 相对路径拼成 `/B/xxx`（不存在）→ `sftp_list_dir` 报 NoSuchFile。
  （绝对路径 `cd /abs` 不受影响，`joinPath` 对绝对路径是直通 —— 所以只有相对 `cd` 才会炸，容易误判成"某些目录有问题"。）
- 修法（单一事实来源）：**终端解析、面板只跳**。
  - `remote-cwd.ts::noteCd` 返回值由 `void` 改为 `string | null`（`resolveCd` 的结果，与 shell 同语义：`~` / `-` / `..` / 相对路径全支持）。
  - `TerminalView` 在提交命令处把该绝对目标写进 follow：`setFollow({nonce+1, path: cdTarget})`。
  - `RemoteFilePanel` 的跟随 effect 简化成 `void load(followPath)`；删掉 `home` state 与 `joinPath`（utils.ts 的 `joinPath` 已无引用，一并删除）。
  - `remote-file/utils.ts::FilePanelFollow` 的字段 `arg` → `path`（原本是个没人用的死类型，这次接上）；`ProjectView` 的 `NO_FOLLOW` 同步改。
- 测试：`terminal/test/remote-cwd.test.ts` 新增 3 个（相对路径按终端 cwd 解析 / `~` 与 `-` / 解析不出来返回 null 绝不猜）。

## 提示符精简做成工具开关（用户重申需求后落地）

用户澄清"我说的是提示符"：`root@iZ2zeahqzmii45zto26u2dZ:/#` 要变成 `/#` 这样（只留目录）。

- 新 `views/terminal/terminal-prompt.ts`：偏好键 `bls-ops.terminal.compactPrompt`（**默认关**）+ `COMPACT_PROMPT_COMMAND`。
- 注入命令：` [ -n "$BASH_VERSION" ] && PS1='\[\e]7;file://\h$PWD\a\]\W\$ '`
  - `\[ \]` 包非打印序列（否则 readline 按宽度算错光标）；`\W`=当前目录名（根目录即 `/` → 正好是用户要的 `/#`），`\$` 保留 root 的 `#`；
  - **顺带上报 OSC 7**（`\e]7;file://\h$PWD\a`）→ 拿到权威 cwd，补全与文件面板跟随因此更准；用户只看到 `\W`；
  - `$BASH_VERSION` 门控：zsh / dash / fish 下整条为假，**一个字都不写进去**（绝不在别人 shell 里留看不懂的转义）；前导空格躲历史。
- 注入点：`TerminalView` **连接成功那一瞬间**发一次。**绝不监听偏好变化立即注入** —— 那会在用户正敲命令时往命令行里写字（刚因"强制改用户输入"被否过一次）。设置变更从下一次连接生效。
- 设置页 `settings-terminal.tsx` 加一行 `Switch`（标题「精简提示符」+ 说明"仅本次会话有效，不修改服务器任何配置文件"）；i18n 进 settings.ts。
- 测试：`test/terminal-prompt.test.ts` 6 个（默认关/门控/前导空格/`\W` 无 `\w`/OSC7 与非打印包裹/命令内无单引号）+ 设置页开关渲染 1 个。
