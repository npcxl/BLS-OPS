## 4. 调用关系与依赖

- **视图 → `opsApi`**：所有页面直接 `import { opsApi } from "@/api/ops-api"`；无独立 service 层。
- **视图 → 事件**：`listen(\`ssh-output-${id}\`)`、`project-scan-result-${id}`、`dir-size` 等事件名字符串前后端各自手写，无单一来源。
- **stores**：`workbench-store`（tab/分屏）被 WorkspaceTabs/WorkbenchPane/TabContent/各 View 读写；`session-store` 是连接状态唯一事实源；`monitor-store` 有独立单测。
- **Rust**：commands.rs → 各能力模块（docker/systemd/...）→ remote/safe → ssh.rs；P3 流水线 commands 内联（capability_probe → deployment_collector → project_discovery）。
- **类型流**：Rust serde snake_case ↔ ops-api.ts interface 手工镜像，无代码生成。
